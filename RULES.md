# Codex x TwitchCon Hackathon — rules summary
Source: https://twitchcon-codex.devpost.com/rules (read 2026-10-27)

- Submission period: Oct 23 10:00 PT – **Nov 2, 2:00 PM PT = Nov 3, 3:30 AM IST**.
- Judging Nov 5–15; winners ~Nov 15 at TwitchCon San Diego.
- Prizes: 1st $10K, 2nd $6K, 3rd $4K, 2 runner-ups $2.5K (+ stage time). Travel not covered; not attending doesn't forfeit cash.
- Eligibility: individuals 18+ or teams. India is not excluded. Must be newly built during the submission period.
- Project: built for streamers + community on Twitch **with OpenAI Codex**; must be an interactive experience that connects to Twitch (chat, overlay, Twitch API, EventSub or Extension). Must install and run consistently, as shown in the video.
- Submit: repo URL (GitHub/GitLab/Bitbucket; public, or private shared with testing@devpost.com) with all source + run instructions; text description of features **and how Codex was used**; **Codex session ID** of the thread where it was built; YouTube video, public, <3 min, showing it **working on Twitch** AND **how it was built with Codex**; no copyrighted music/third-party trademarks.
- Project must be free for judges to test through the end of judging.
- English materials.
- Judging: Stage 1 pass/fail (fits theme, uses Codex). Stage 2, equally weighted: Innovation/Idea; Potential Impact (useful/entertaining for streamers and communities); Technical implementation (incl. how well it uses Codex); Design (easy to use, fun to watch). Ties are broken by Innovation first.
- Multiple submissions allowed if substantially different.
