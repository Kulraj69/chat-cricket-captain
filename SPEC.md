Build "Chat Cricket Captain": a Node 20+ app with no build step and minimal deps (ws, tmi.js optional).
- server.js: an HTTP server that serves /overlay (OBS browser source, transparent, 1920x1080) and /mock (a mock-chat page where you type user+message and send it), plus a WebSocket that pushes state to the overlay.
- src/game.js: a pure game engine. Each ball opens a vote window (default 15 s, configurable). Commands: !drive !pull !sweep !defend !six (one vote per user per ball, last vote counts). The bowler delivery type is random (seeded RNG injectable): yorker, bouncer, spinner, slower, full toss. An outcome matrix maps shot x delivery to a probability distribution over 0,1,2,4,6,W. Track the score, wickets, overs (6 balls), and a target chase (default 36 off 3 overs), plus a win/lose state. Per-user stats: votes, runs credited when your shot won the vote, MVP. Events: channelPointRedeem "DRS" overturns the last wicket with 50% odds (one per innings), raid -> "Super Over" mode, cheer/bits -> "Free Hit" next ball.
- src/commentary.js: template-based witty commentary (Hinglish flavor, English-first), deterministic with RNG.
- src/twitch.js: if TWITCH_CHANNEL and TWITCH_BOT_USERNAME and TWITCH_OAUTH_TOKEN are set, connect via IRC (tmi.js) and announce results in chat; optional EventSub WebSocket (TWITCH_CLIENT_ID + user token with channel:read:redemptions, bits:read, moderator:read:followers) to map redemptions/cheers/raids to events. Otherwise use mock mode.
- public/overlay.html: a nice animated scoreboard, a vote bar chart, a ball animation, a commentary ticker, and an MVP list, with a cricket-pitch aesthetic.
- tests using node:test (npm test) covering the vote tally, outcome determinism, wickets/overs/chase end, DRS, free hit, super over, and the message parser.
- README.md: what it is, quick start (npm i; npm start; open /mock and /overlay), OBS setup, the exact Twitch credentials/scopes needed, how it was built with Codex. MIT LICENSE (Copyright 2026 Kulraj Singh Sabharwal). .gitignore with node_modules and .env. .env.example.
Run npm install and npm test until it passes. Be efficient.
